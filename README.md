# Ruhul Amin Portfolio - React Vite JSX

A premium portfolio website built with React, Vite, JSX, Tailwind CSS, React Router, React Icons and Formspree.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Dependencies used

```bash
npm install react react-dom react-router-dom react-icons vite @vitejs/plugin-react tailwindcss @tailwindcss/vite
```

## Formspree endpoint

The endpoint is stored in `.env`:

```env
VITE_FORMSPREE_ENDPOINT=https://formspree.io/f/xlgkrvar
```

## CV Download
